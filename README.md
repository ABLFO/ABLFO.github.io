# TGA Chanukah Raffle: live drawing page

- Watch page: the site's home page. Organizer desk: the same address ending in `#run` (password protected).
- Drawings are signed with the organizer's key and sent through ntfy.sh, so open pages update within a second.
- `state.json` is a lasting copy of the latest signed results, kept current by the "Keep raffle results" workflow.
